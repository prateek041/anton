# Introduction

Welcome to **Anton OS** documentation.

This book is built with [mdBook](https://rust-lang.github.io/mdBook/). Edit Markdown under `docs/src/` and use `make docs` from the project root for a live-reloading preview.

## Next steps

- Add chapters in `docs/src/` and list them in `docs/src/SUMMARY.md`.
- Run `make docs-build` for a one-shot HTML build (output: `docs/book/`).
