# Setting up the development Environment

So at this step, we are trying to think, what our development environment
should look like.

For any development environment a few things matter the most:

- How fast can I make changes
- How fast can I see the affect of changes I made
- How fast can I re-create the environment by destroying
- How maintainable is it?

Now, to get answers for all these questions, there are different types of
tools that already present in the world.
