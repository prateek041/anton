# Hot Reloading

Hot reloading is the mechanism used while developing software where the developer
can see the affect of changes they made to their code in real-time, the moment
they save their changes. Most of the Web Development engineers are quite familiar
with it, they make changes to something an HTML file and can see the affect
of their changes directly in the browser.
