# Introduction

Welcome to **Anton OS** documentation.

This book is all about building an Operating System from scratch, without
getting bored. I as the writer, wrote this book not at the end of mastering the
art, but while I was mastering it. You can even look at the mistakes I made while
building the project itself if you take a closer look at the history of the project.

Let's get started.

We are going to do it in multiple phases and each phase we are going to build
something from scratch, and start with first principles, no big words, no fancy
technology, even the complex mathematics involved, we don't learn it at the very
beginning, we learn it when come to find the need of it.

The first thing to understand is that computer is not magic. Everything put into
it works a certain way, that it is expected to, and only then, do we get a machine
that does what we tell it to and even some magic.
